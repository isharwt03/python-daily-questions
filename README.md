Master the essentials of Python loops and list operations.

#### Questions Covered:
1. **Print numbers 1-10** - Using a for loop to iterate through a range
2. **Multiplication Table** - Generate multiplication tables for any number
3. **Sum of List Elements** - Calculate the sum of all elements in a list
4. **Max and Min Values** - Find maximum and minimum values in a list
5. **Reverse a List** - Reverse a list using the `.reverse()` method
6. **Count Occurrences** - Count how many times a number appears in a list
7. **List Comprehension** - Create a list of squares using list comprehension
8. **String Character Loop** - Print each character of a string on a new line
9. **Vowels and Consonants** - Count vowels and consonants in a string
10. **Palindrome Check** - Check if a number is a palindrome using string reversal

#### Key Concepts:
- ✨ For loops and range()
- ✨ List operations (reverse, count, max, min, sum)
- ✨ List comprehension
- ✨ String iteration and slicing
- ✨ Conditional statements in loops
